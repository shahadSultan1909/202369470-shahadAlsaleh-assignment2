01

File System Simulator

Loading GitHub info…

A command-line file system simulator built in Java that mimics Unix-like commands (mkdir, cd, ls, pwd, touch, grep, rm, tree). Implements a custom tree structure, a generic stack, and the KMP algorithm for pattern searching inside files.

Java Data Structures KMP Algorithm

Biggest challenge

Deciding which data structures fit the project best. I had to choose how to represent folders and files, how to store each folder's children, and how to build a path for pwd.

What I learned

I became more confident choosing data structures for a real problem. I used a tree for the hierarchy, a HashMap with an ArrayList for children, and a stack for pwd. I also improved my Java.

02

Smart Pedestrian Crossing System

Loading GitHub info…

A digital system designed in Verilog HDL and implemented on a Digilent Nexys A7 FPGA. Controls traffic lights for three roads and a pedestrian crossing using a 4-state Moore FSM, a 1 Hz clock divider, and a live countdown on a 7-segment display.

Verilog HDL FPGA Finite State Machines

Biggest challenge

It was my first time working with Verilog. Implementing the pedestrian feature was the hardest part, because it is not a normal light: the button can be pressed at any time, but the request must wait until the current phase ends.

What I learned

I learned to design with Verilog and logic, and to run it on an FPGA board. I also learned how to think about timing and states in hardware.

A machine learning project predicting mobile phone price ranges from hardware specifications, comparing KNN, SVM, and MLP on a 2,000-sample dataset. A linear-kernel SVM performed best, reaching 95.3% accuracy across four price classes.
